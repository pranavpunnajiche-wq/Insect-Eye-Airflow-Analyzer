# 🦟 Insect Eye – Airflow Analyzer

### Neuromorphic Optical Flow Array for Micro-Vortex Detection

## 📌 About the Project

The Insect Eye Airflow Analyzer is a Python-based software prototype inspired by the compound eyes of insects. It combines airflow visualization, simulated optical-flow sensing, pressure-based airspeed calculations, and vorticity analysis in an interactive dashboard.

The project aims to demonstrate how an insect-inspired sensing system could help visualize airflow patterns and investigate rotational flow structures.

## 🎯 Objectives

- Calculate airspeed using pressure differences.
- Visualize illustrative airflow around an aerofoil.
- Simulate an insect-inspired optical-flow sensing array.
- Calculate vorticity from a simulated two-dimensional velocity field.
- Display airflow analysis results in an interactive dashboard.

## ✨ Features

- **Pressure Calculator:** Estimates airspeed using total pressure, static pressure, and air density.
- **Airflow Visualization:** Displays illustrative streamlines around an aerofoil.
- **Optical Flow Array:** Visualizes a grid of simulated velocity vectors.
- **Micro-Vortex Analysis:** Calculates and visualizes vorticity in the simulated flow field.
- **Interactive Dashboard:** Allows users to change simulation parameters and view updated results.
- **Sensor Data Table:** Displays sample values generated by the simulation.

## 🧮 Airspeed Calculation

The prototype uses the low-speed Pitot equation:

**V = √(2 × (Pt − Ps) / ρ)**

Where:

- V = Estimated airspeed in metres per second
- Pt = Total pressure in pascals
- Ps = Static pressure in pascals
- ρ = Air density in kilograms per cubic metre

This approximation assumes suitable pressure measurements and approximately incompressible airflow.

## 🔬 Current Prototype Limitations

- Airflow and optical-flow data are simulated.
- The dashboard is not connected to physical sensors.
- The aerofoil visualization is illustrative, not a validated CFD simulation.
- Vorticity visualization indicates rotation in the simulated velocity field; it does not establish real-world micro-vortex detection.
- Experimental validation and hardware integration are future development goals.
